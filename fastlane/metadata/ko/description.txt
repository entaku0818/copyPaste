복사한 내용을 자동으로 저장하고 필요할 때 텍스트, 링크, 이미지를 다시 찾아보세요. 위젯이나 사용자 설정 키보드에서 기록을 확인할 수 있습니다.

무료 기능
• 최근 3일간 최대 20개 항목 자동 저장
• 텍스트, 이미지, URL 지원
• 이미지 속 글자를 포함해 기록 검색
• URL, 이메일, 전화번호, 코드, 주소, 텍스트 자동 분류
• 즐겨찾기 최대 10개, 텍스트 조각 최대 3개
• 대소문자, 줄바꿈, 앞뒤 공백 변환
• iCloud로 최대 20개 항목 동기화
• 사용자 설정 키보드에서 기록과 텍스트 조각 확인

ClipKit Pro
