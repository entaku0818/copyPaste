ClipKit stores clipboard history and displays recent items in a Picture in Picture window while the user works in other apps. The PiP implementation uses AVPictureInPictureVideoCallViewController with a custom clipboard history view.

Version 1.7.7 verification:
1. Complete onboarding and open the monitoring tab (「常時起動」 in Japanese).
2. Tap Open PiP to display the clipboard history window.
3. Enable Compact PiP to hide the header and request a shorter window. iOS controls the final PiP window size; the app does not change system window transparency.
4. In Apple's Shortcuts app, add ClipKit's Open PiP action. Running it opens ClipKit, starts monitoring, and requests PiP after the UI is ready. On supported iPhones, the shortcut can be assigned to the Action button.
5. The contact form in Settings now includes category-specific guidance and an optional reply email address.

No account is required to use the app. Subscription purchases can be tested in the App Store sandbox.
